# Architectural Decisions

Records of significant design decisions: what was decided, the context it was
decided in, the alternatives that were rejected, and any caveats attached at
acceptance. Numbered in decision order; a record is immutable once accepted —
if a decision is revisited, supersede it with a new record rather than editing
history.
